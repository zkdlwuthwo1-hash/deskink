# 04: PC 두 대 전환 및 필기 복원

**What to build:** PC 한 대씩 연결하며 필기를 PC·모니터별로 저장하고 재연결·앱 재시작 후 복원한다.

**Blocked by:** 03
**Status:** ready-for-agent

2026-10-18: 사용자가 같은 PC의 화면별 바로가기/Stream Deck 전환을 먼저 요청했다. 화면별 메모리 필기·실행 취소 보존과 구형 iPad 보호를 구현했다. Windows 실제 바로가기→화면 1→2→1 캡처 검사, 입력 세대 분리 검사와 iPad 163개 단위/2개 UI 검사가 통과했다. IPA 빌드 11의 실기기 설치·USB 전환 확인은 남았다. 아래 PC 두 대 등록·영구 저장·재시작 복원 전체 작업은 완료 처리하지 않는다.

- [x] 같은 PC의 모니터 전환 시 필기와 실행 취소 기록 분리 (양쪽 자동 검사).
- [ ] 빌드 11의 실제 USB 모니터 전환·Pencil 검증.

- [ ] 다른 PC의 필기가 혼합되지 않는다.
- [ ] 중복·이전 세대의 메시지가 현재 필기를 변경하지 않는다.
