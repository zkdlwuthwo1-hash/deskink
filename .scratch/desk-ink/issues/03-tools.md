# 03: 발표용 도구 사용하기

**What to build:** 기본 도구와 색·굵기, 실행 취소·다시 실행, 전체 지우기·숨기기 및 지원 기기 더블탭을 제공한다.

**Blocked by:** None (사용자가 도구 구현을 먼저 요청해 02와 구현 순서를 조정)
**Status:** in-progress

2026-10-16: FPS 수정의 실기기 확인과 별개로 지우개 등 발표 도구를 먼저 구현한다. 확대 작업 02는 남겨 두고 완료로 표시하지 않는다. 지우개는 선 단위 삭제, 한 번의 지우개 제스처는 실행 취소 한 번으로 복원한다.

추가 사용자 요구: 도구막대 또는 Pencil 더블탭으로 지우개를 선택해 사용한 뒤, 펜을 화면에서 떼면 직전 필기 도구로 자동 복귀한다. 색과 굵기는 유지한다.

- [x] 펜·형광펜·지우개·레이저·사라지는 펜 구현 및 자동 검사.
- [x] 전체 지우기와 숨기기를 구분한다.
- [ ] 반투명 필기와 지우기 결과가 양쪽 화면에서 일치한다.

Windows 픽셀 검사로 지우기·취소·숨기기·보이기를 확인했다. 자동 복귀를 포함해 iPad 전체 테스트 160개가 통과했다. 빌드 8 IPA와 Windows Release 실행물을 준비했다. 새 IPA를 실제 기기에 업데이트하고 Pencil 더블탭·펜을 뗀 뒤 복귀 및 양쪽 필기 일치를 확인하기 전까지 in-progress를 유지한다.
