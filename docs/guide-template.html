02 / Install

사용할 태블릿을 골라주세요.

처음 한 번 설치와 연결 허용을 마칩니다. Mac이나 개발 도구는 필요 없습니다.

iPad에 설치하기

iPadOS 17+

  1. PC에서 Windows 앱 실행

    Windows ZIP을 문서 폴더 등 쓰기 가능한 위치에 전체 압축 해제한 뒤 DeskInk.exe를 엽니다. 영상 구성요소 약 60MB를 처음 한 번 내려받습니다.

    바탕화면에 DeskInk - Screen 1 / Screen 2 아이콘이 생깁니다. 압축을 푼 폴더의 파일들은 함께 보관하세요.

  2. USB 연결하고 컴퓨터 신뢰

    아이패드를 데이터 USB 케이블로 연결하고 잠금을 풉니다. 이 컴퓨터를 신뢰가 나오면 허용하세요.

    Apple Devices 앱 자체는 필수가 아닙니다. 이미 DeskInk가 아이패드를 인식한다면 추가 설치·실행 없이 진행합니다. 연결되지 않을 때만 iTunes 또는 Apple Devices가 제공하는 Apple USB 드라이버·연결 서비스를 확인하세요.

  3. iloader에서 iPad 앱 설치

    PC에 받은 iloader 설치 파일을 실행합니다. 설치된 iloader에서 아이패드를 선택하고 본인 Apple 계정으로 로그인·이중 인증합니다.

    Import IPA / IPA 가져오기
    → DeskInk-iPad-unsigned.ipa 선택
    → Sign & Install App → 설치 완료

    Windows에서 iTunes 등 Apple 구성요소가 필요하다는 안내가 나오면 iloader 공식 안내를 따르세요. 설치가 끝나면 iloader는 닫아도 됩니다.

  4. 개발자 신뢰와 개발자 모드 켜기

    “개발자를 신뢰할 수 없음”이 나오면 다음 설정에서 본인 계정을 신뢰합니다.

    설정 → 일반 → VPN 및 기기 관리
    → 개발자 앱 → 본인 Apple 계정 → 신뢰

    그다음 개발자 모드를 켭니다.

    설정 → 개인정보 보호 및 보안
    → 개발자 모드 → 켜기 → 재시동

    재시동 후 잠금을 풀고 확인창의 ‘켜기’를 한 번 더 누르세요. 기기 암호를 요청하면 입력합니다. Apple 공식 안내

    메뉴가 없다면 iloader로 IPA를 설치하고 DeskInk 실행을 한 번 시도한 뒤 설정을 다시 여세요. 학교·회사 관리 기기는 설정이 제한될 수 있습니다.

무료 Apple 계정은 7일마다 설치를 갱신합니다.

USB로 연결하고 iloader에서 같은 계정·같은 IPA → Sign & Install App을 다시 실행하세요. Apple 계정 자체가 만료되는 것은 아닙니다. Apple 무료 계정 안내

설치했으면, 페어링 코드 입력하기

Galaxy Tab에 설치하기

Android 8+

  1. 태블릿에서 APK 다운로드·설치

    태블릿에서 Android APK 다운로드를 누릅니다. 받은 파일을 열어 설치를 누르고, 요청하면 해당 브라우저·내 파일 앱의 이 출처 허용을 켭니다.

  2. 개발자 옵션에서 USB 디버깅 켜기

    설정 → 태블릿 정보 → 소프트웨어 정보
    → 빌드번호 7번 탭 → 기기 암호 입력
    → 설정 → 개발자 옵션 → USB 디버깅 켜기

    기기마다 메뉴 이름이 조금 다를 수 있습니다. 삼성 공식 안내

  3. PC에서 Android 연결 준비

    Windows ZIP을 전체 압축 해제하고 DeskInk-Android.exe를 처음 한 번 엽니다. USB 구성요소 약 8MB와 영상 구성요소 약 60MB를 내려받으므로 인터넷이 필요합니다.

    다음부터 바탕화면의 DeskInk - Screen 1 / Screen 2 중 원하는 아이콘을 열면 됩니다.

  4. USB로 연결하고 PC 허용

    데이터 USB 케이블로 연결하고 태블릿에서 이 컴퓨터에서 USB 디버깅 허용을 누릅니다. 태블릿의 DeskInk를 열어 두세요. Android 태블릿은 한 번에 한 대만 연결합니다.

S펜 버튼을 누르는 동안 지우개.

버튼을 놓으면 이전 도구로 돌아옵니다. 버튼 없는 펜은 도구막대의 지우개를 사용하세요. Android는 Apple 계정이나 iloader 없이 설치하며, 7일마다 갱신하지 않습니다.

설치했으면, 페어링 코드 입력하기

03 / Pair your PC

PC의 숫자를,
태블릿에 그대로 입력하세요.

페어링 코드(Pairing code)는 연결할 PC를 확인하는 6자리 숫자입니다. PC의 DeskInk 창에서 보고, 태블릿의 DeskInk 앱에 입력합니다.

iPad·Galaxy Tab 공통
코드 위치와 입력 화면 예시아래 숫자는 설명용입니다.
1. Windows PC
DeskInk
Screen 1Screen 2

Connect your tablet by USB and open DeskInk

Pairing code482691
2. 태블릿
PC의 6자리 코드 입력

PC에 표시된 숫자를 그대로 옮깁니다.

482691
iPad: Pair iPad / Android: 연결
입력은 태블릿 앱에서 합니다.

화면 구성은 설명을 위해 단순화했습니다. 482691을 입력하는 것이 아니라, 지금 PC에 표시된 코드를 사용하세요. 이 안내 페이지에서는 앱을 연결하지 않습니다.

  1. PC에서 DeskInk 창과 코드 찾기

    PC에서 DeskInk를 실행하고 Screen 1 / Screen 2로 사용할 화면을 고릅니다. 창 안의 연결 상태 문구 아래에 있는 Pairing code: 6자리 숫자를 확인하세요. 창을 최소화했다면 작업 표시줄의 DeskInk를 눌러 다시 엽니다.

  2. USB를 연결하고 태블릿의 입력창 열기

    iPad: 잠금을 풀고 DeskInk를 열면 Pair with your PC / Pair with PC 입력창이 나타납니다.

    Galaxy Tab: 입력창이 자동으로 뜨면 사용하고, 보이지 않으면 시작 화면의 PC 연결 / Pair PC 버튼을 누릅니다. 연결 대기 중에는 왼쪽 위 연결 상태를 눌러도 입력창이 열립니다.

  3. 6자리를 입력하고 연결 버튼 누르기

    PC에 표시된 숫자를 앞자리 0까지 모두 입력합니다. iPad에서는 Pair iPad, Android에서는 연결 / Connect을 누르세요. Apple 계정의 이중 인증 번호와는 별개입니다.

  4. Windows 화면이 태블릿에 보이면 완료

    태블릿에 PC 화면이 표시되고 PC 창에 Tablet connected가 나타나면 펜으로 쓰면 됩니다. 연결 직후 PC의 코드가 바뀌는 것은 정상입니다. PC DeskInk를 종료했다가 다시 켜면 새 코드로 다시 연결하세요. 같은 실행 중 화면 1·2를 전환할 때는 보통 다시 입력하지 않습니다.

코드 입력에서 막혔다면

PC에 코드가 안 보여요.

iloader나 Apple Devices가 아니라 Windows의 DeskInk 창을 엽니다. ZIP을 전체 압축 해제하고 iPad는 DeskInk.exe, Android는 첫 설정 때 DeskInk-Android.exe를 실행하세요. 바탕화면 아이콘으로 실행한 경우 작업 표시줄에서 DeskInk 창을 찾습니다.

태블릿에 입력창이 안 떠요.

PC와 태블릿 양쪽에서 DeskInk를 열고 USB 케이블을 확인하세요. iPad는 컴퓨터 신뢰와 Apple USB 연결 서비스를 확인합니다. 앱의 USB 항목이 꺼져 있으면 Turn on, 연결이 끊긴 상태라면 표시된 Connect USB를 누릅니다. Android는 USB 디버깅 허용 후 시작 화면의 PC 연결을 누릅니다. 이미 PC 화면이 보이면 연결된 상태입니다.

코드가 틀렸거나 너무 많이 시도했다고 나와요.

PC 창의 현재 코드를 다시 보고 6자리를 입력하세요. 재시작하거나 연결에 성공하면 숫자가 바뀔 수 있습니다. Too many attempts / 시도 횟수가 많습니다가 나오면 1분 기다린 뒤 다시 입력합니다.

iPad 안내에 EternalMonitor라고 나와요.

현재 iPad 앱의 일부 안내에 남아 있는 이름입니다. 실제 코드는 Windows DeskInk 창의 Pairing code에서 확인하면 됩니다. 이 안내의 USB 연결에서는 PC 주소나 포트를 직접 입력하지 않아도 됩니다.

04 / Write & present

펜은 태블릿에서.
설명은 Windows 화면에.

태블릿 아래 도구막대에서 펜을 고릅니다. PC 조작은 평소처럼 마우스와 키보드로 합니다.

펜·형광펜

필기를 남기고 강조합니다. 색상과 굵기를 선택할 수 있습니다.

지우개

닿은 선을 통째로 지웁니다. 도구막대 지우개는 펜을 떼면 이전 도구로 복귀합니다. S펜은 버튼을 누르는 동안 지우개, 지원 Pencil은 두 번 탭으로 전환합니다.

레이저·사라지는 펜

위치를 가리키거나 약 2초 뒤 사라지는 필기를 남깁니다. 펜을 화면에 대기 전 포인터 표시는 호버 지원 기기가 필요합니다.

취소·다시·숨기기·전체 지우기

현재 화면의 필기를 되돌리거나 숨깁니다. 휴지통은 현재 화면을 모두 지우며, 전체 지우기도 취소할 수 있습니다.

태블릿에서만 확대

두 손가락을 벌리면 1~4배 확대, 두 손가락으로 끌면 이동합니다. 화면 맞춤으로 원래 배율에 돌아옵니다. Android에서는 오른쪽 위의 네 모서리 아이콘입니다. PC 화면의 배율은 그대로이며, 손가락으로는 필기되지 않습니다.

모니터 1·2 전환

바탕화면의 DeskInk - Screen 1 / Screen 2 아이콘을 더블클릭합니다. 터미널 창 없이 화면이 전환되고 영상은 잠시 다시 연결됩니다. Stream Deck에도 같은 아이콘을 등록할 수 있습니다. 아이콘을 다시 만들 때는 DeskInk-Shortcuts.exe를 실행하세요. DeskInk의 화면 번호는 Windows 설정 번호와 다를 수 있습니다.

Zoom에서 발표

Zoom에서 직접 필기하는 모니터 전체를 공유합니다. 다른 참가자에게 필기와 포인터가 보이는지 확인하세요. 특정 앱 창만 공유하면 필기가 빠질 수 있습니다.

다시 사용하거나 종료

다음에도 USB 연결 → PC·태블릿 DeskInk 실행 → 페어링 순서로 시작합니다. 화면마다 필기가 따로 유지되지만, Windows DeskInk를 종료하면 모든 필기가 지워집니다. 사용 중에는 DeskInk와 USB 연결을 유지하세요.

05 / Help

막힌 부분부터 확인하세요.

Windows 앱이 실행되지 않아요.

ZIP 안에서 바로 실행하지 말고 전체 압축을 풀어 주세요. 첫 실행에는 인터넷과 폴더 쓰기 권한이 필요합니다. 오류 로그는 %LOCALAPPDATA%/DeskInk/logs에서 확인할 수 있습니다.

아이패드가 PC에 나타나지 않아요.

잠금 해제와 이 컴퓨터 신뢰를 확인하고, 데이터 전송용 케이블과 다른 USB 포트를 사용해 보세요. 계속 인식되지 않으면 설치한 iTunes 또는 Apple Devices에서 기기 인식을 확인합니다. iTunes의 연결 서비스 오류는 Apple 서비스 점검 안내를 참고하세요.

Apple Devices를 계속 열어 둬야 하나요?

모든 PC에서 필요한 것은 아닙니다. DeskInk는 Apple의 USB 연결 서비스가 동작하면 연결할 수 있습니다. Apple Devices를 열지 않아도 정상 연결된다면 그대로 사용하세요. 해당 앱을 닫았을 때 연결이 끊기는 환경에서만 사용 중 최소화해 두면 됩니다.

갤럭시탭이 PC에 나타나지 않아요.

DeskInk-Android.exe로 첫 설정을 했는지 확인하세요. USB 디버깅을 켜고 태블릿에서 이 PC를 허용합니다. 앱을 열어 두고, 필요하면 삼성 USB 드라이버를 설치하세요.

개발자의 앱을 사용할 수 없다고 나와요.

iPad의 개발자 신뢰·개발자 모드 설정을 확인하세요. 재시동 후 켜기 확인까지 마쳐야 합니다. 설치한 지 일주일이 지났다면 iloader에서 서명·설치 갱신을 진행하세요.

페어링 코드 입력이 어려워요.

PC에서 코드 찾기 → 태블릿에 입력하기 안내를 보세요. 코드가 안 보이거나, 입력창이 없거나, 오류가 날 때의 해결 방법을 함께 정리했습니다.
