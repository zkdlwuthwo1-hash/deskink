# Windows 0.5.3 실행 파일 통합 검증

2026-10-22. iPad·Android용 PC 실행을 `DeskInk.exe` 하나로 통합했다.
태블릿 앱은 0.5.1을 유지하며 Windows 캡처·영상·필기 및 네이티브 런처 바이너리는
0.5.2 배포 파일과 동일하다. 변경 범위는 시작 스크립트, ZIP 구성, 설치 안내다.

## 동작

- 호스트 시작을 확인한 뒤 `start-android.ps1 -PrepareOnly`를 숨김 자식 프로세스로 실행한다.
- 업데이트 시작 영수증은 선택 구성요소 준비 전에 기록한다. 다운로드 실패나
  준비 프로세스 실행 실패가 정상 호스트를 종료하거나 업데이트를 되돌리지 않는다.
- 이미 실행 중인 호스트의 모니터 전환과 `-CheckOnly` 진단은 Android 준비를 시작하지 않는다.
- Google의 기존 고정 URL·SHA-256을 유지한다. 준비된 캐시는 재사용하며 새 구성요소는
  별도 임시 폴더에서 검증·추출을 끝낸 뒤 한 번에 설치 위치로 옮긴다.
- 백그라운드 다운로드 제한은 기본 60초다. 실패하면 다음 전체 실행에서 다시 시도한다.
- 새 ZIP의 최상위 실행 파일은 `DeskInk.exe` 하나다. 기존 manifest가 관리하던
  Android·바로가기 생성 EXE는 앱 내 업데이트 과정에서 제거된다.
- 기본 화면 1·2 바로가기 자동 생성과 기존 바로가기 경로는 유지한다.

## 자동 검사

`tdd` 절차로 먼저 실패를 확인한 뒤 동작을 구현했다. 준비만 요청했는데 호스트를
실행하던 문제, 실패한 다운로드가 설치 폴더를 미리 노출하던 문제, 공통 런처에서
Android 준비가 시작되지 않던 상황을 재현했다.

검사는 임시 설치 폴더와 임시 `LOCALAPPDATA`를 사용한다. 실행 중인 사용자 DeskInk를
종료하거나 설정·필기·바탕화면을 변경하지 않는다.

```powershell
python scripts/test-android-setup.py -v
python scripts/test-portable-launcher.py
python scripts/test-windows-updater.py
```

- Android 준비: 캐시 재사용, 호스트 중복 실행 방지, 오프라인 오류, 정체된 다운로드의
  시간 제한, 실패한 갱신에서 기존 파일 보존, 기존 모니터 지정 실행.
- 실제 Google 배포 파일을 내려받는 선택 검사도 별도로 통과했다. 설치 폴더를 관찰해
  불완전한 파일 조합이 노출되지 않았음을 확인했고 실제 `adb version` 실행도 성공했다.
  네트워크 검사는 `DESKINK_SETUP_NETWORK_TEST=1`로 선택한다.
- 공통 런처: 느린 준비·실패한 준비와 무관한 호스트 시작 및 업데이트 영수증,
  준비 프로세스 실행 실패 로그, 호스트 실패 시 영수증 미생성, 기존 진단·화면 전환.
  실제 자식 프로세스로 검사하되 OS 프로세스 조회는 임시 테스트 호스트로 한정한다.
- 업데이트: 12개 기존 검사에 옛 Android·바로가기 EXE 제거 확인을 추가했다.
  런타임 캐시와 사용자 파일은 유지된다.
- HTML: 1440·820·390·320px에서 Windows 다운로드 우선 배치, 기기 탭·키보드·앵커,
  이미지 확대와 초점 복귀, 인쇄·JavaScript 비활성화, 오프라인 이미지 표시를 확인했다.

이번 검증은 실행·준비·패키징 경계에 대한 것이다. 갤럭시탭 실기기의 새 연결 감각이나
필기 지연을 다시 측정한 것은 아니며, 장시간 사용 시 지연·무선 필기 가림 증상의
해결을 주장하지 않는다. 강제 파일시스템 장애 중 복구 실패는 방어 코드로 검토했으며
해당 장애를 실제 주입하지 않았다.

## 배포 파일 확인

- clean source `2fb0a6d`에서 Windows 0.5.3 ZIP을 생성하고 manifest의 564개 파일 해시를 검사했다.
- ZIP을 공백이 있는 임시 경로에 풀어 실제 영상 런타임의 `-CheckOnly`를 실행했다.
  임시 바탕화면에 생성한 두 바로가기의 대상과 `--monitor 0/1` 인수도 확인했다.
- 공개 `v0.5.3`과 기존 다운로드 주소용 `v0.4.0-lab.1`에서 ZIP·IPA·APK·HTML·APK 서명 안내·
  체크섬 파일을 모두 다시 내려받아 로컬 파일과 SHA-256이 일치함을 확인했다.
- Windows ZIP SHA-256: `65f4801b180980e9726998a81f4f78589d76f97ded4e251afb3132df99a9e3c8`.
  IPA·APK는 기존 0.5.1과 동일하다. 실행 중인 사용자의 기존 Windows 앱은 종료하지 않았다.
