# 확정한 요구사항

이 문서는 대화에서 사용자가 정한 요구사항을 기록합니다. 기술 선택과 아직 검증하지 않은 성능은 별도 설계 문서에서 구분합니다.

## 2026-10-23 추가: 앱 안에서 업데이트

- 사용자는 무료 배포 방식을 유지하고 Windows·Android부터 앱 안에서 업데이트하기로 선택했습니다. Apple Developer 가입이나 TestFlight 전환은 진행하지 않습니다.
- Windows는 기존 앱 내 다운로드·설치·재시작 흐름을 유지합니다. Android는 새 버전 확인, 검증된 APK 다운로드, Android 설치 확인창으로 연결합니다. 발표 중 강제로 설치하거나 재시작하지 않습니다.
- Android 기존 버전은 업데이트 기능이 들어 있는 0.6.0 APK를 한 번 직접 설치해야 합니다. 이후 배포는 앱 안에서 받으며 PC 등록·설정을 유지합니다. 완전 무인 설치는 요구하거나 약속하지 않습니다.
- iPad는 같은 Apple 계정의 iloader 설치와 무료 서명 갱신을 유지합니다.
- 지우개는 작게·중간·크게 3단계로 선택을 기억합니다. 크기는 일반 지우개와 펜 버튼 전환에 동일하게 적용합니다.

## 사용자와 기기

- 우선 사용자 본인이 사용합니다. 이후 타인에게 배포할 수 있는 구조를 유지합니다.
- Windows PC 두 대를 등록하고, iPad에서 한 번에 한 대를 선택해 연결합니다.
- 현재 사용 기기는 iPad Air와 Apple Pencil 2입니다. 지원 OS 범위 안의 다른 iPad와 입력 장치도 기본 기능을 사용할 수 있어야 합니다.
- PC별 연결 정보와 필기를 구분합니다. 모니터가 여러 개인 PC에서는 필기할 모니터를 선택합니다.
- 같은 PC의 화면 1·2 바로가기 또는 Stream Deck 버튼으로 실행 중인 앱의 모니터를 전환합니다. 화면 1의 필기는 화면 1에, 화면 2의 필기는 화면 2에 유지합니다. 실행 취소 기록도 화면별로 구분합니다. 사용자가 2026-10-18에 선택한 동작입니다.
- PC 조작은 기존 마우스로 합니다. 앱의 필기층이 Windows 마우스 조작을 가로막지 않아야 합니다.
- Zoom 화면 공유는 사용자가 직접 합니다. 앱이 Zoom을 조작하거나 회의를 시작하지 않습니다.

## 발표 흐름

1. Windows 프로그램을 실행해 두고 iPad를 연결합니다.
2. iPad 앱에서 기억된 PC와 모니터를 선택합니다. 정상 재연결에서는 불필요한 설정을 반복하지 않습니다.
3. Windows 화면을 보며 펜으로 필기합니다. Windows에는 동일한 필기와 펜 위치 표시가 나타납니다.
4. 사용자는 평소처럼 Zoom에서 모니터 하나를 공유합니다.
5. 필기 숨기기, 전체 지우기, 도구 전환을 짧은 동작으로 수행합니다.

## 화면과 필기

- Windows의 임의 화면 위에 필기합니다. PowerPoint 전용 기능이 아닙니다.
- iPad에서 화면을 확대·이동해도 Windows의 배율은 변하지 않습니다.
- 두 손가락 벌리기·오므리기로 확대·축소하고 두 손가락 드래그로 이동합니다. 도구막대는 고정하며 화면 맞춤으로 원래 보기로 돌아갑니다. 사용자는 현재 이 기능을 우선 완성하도록 요청했습니다.
- 도구막대는 아래쪽 검은 영역에 두고 영상을 가리지 않습니다. 영상은 도구막대 위 공간에 비율을 유지해 전체가 보이도록 맞추며, 확대된 영상과 필기도 도구막대 영역을 침범하지 않습니다.
- iPad Air 가로 화면에서는 베젤 바로 옆의 불필요한 작은 좌우 여백을 없앱니다. 영상 비율을 왜곡하거나 위·아래를 잘라 채우지 않습니다. 화면별 바로가기와 Stream Deck 전환에서 터미널 창이 나타나지 않아야 합니다.
- 확대 상태의 입력은 선택한 Windows 모니터의 원래 좌표에 정확하게 대응합니다.
- PDF 스크롤이나 PPT 페이지 전환 후에도 필기는 화면 위치에 유지됩니다. 문서 내용에 붙여 추적하지 않습니다.
- 필기는 사용자가 지우거나 숨깁니다. 전체 지우기와 숨기기는 서로 다른 동작입니다.
- Windows DeskInk 실행 중에는 화면별 필기를 유지합니다. 사용자의 이후 답변 “종료해도 돼. 기존필기 필요없어”에 따라 Windows 앱 종료 후 영구 저장·복원은 필수 범위에서 제외합니다.

## 첫 버전 도구

- 펜, 형광펜, 지우개, 레이저 포인터, 일정 시간 후 사라지는 펜
- 색과 굵기 선택
- 실행 취소 / 다시 실행
- 전체 지우기 / 필기 숨기기
- Apple Pencil 2의 더블탭으로 지우개 전환
- 지운 뒤 펜을 화면에서 떼면 직전에 쓰던 도구로 자동 복귀하고 색·굵기를 유지
- 펜 또는 레이저의 위치를 Windows 화면에 표시

첫 버전에서는 도형 자동 생성을 제외했으며, 이후 추가 요청은 아래 확장 범위에 기록합니다.

압력, 기울기, 더블탭, 호버는 장치가 제공하는 기능만 사용합니다. 일반 터치와 Pencil 입력을 구분할 수 없는 입력 장치는 별도 터치 필기 모드가 필요할 수 있습니다. Pencil 2를 지원하는 iPad Air에서 공중 위치 추적을 가정하지 않습니다.

## 도형 보정·선택 편집 확장 — 2026-10-23

사용자는 `grill-me` 인터뷰의 Q1~Q8에 답하고 “일단 추천대로 해보고”로 진행을 요청했습니다.
Q5는 추천과 달리 실행 취소 한 번에 도형 전체를 삭제하는 방식을 선택했습니다.

- iPad와 Android에서 펜·형광펜으로 한 획을 그린 뒤, 펜을 떼지 않고 끝점에서 약 1초 멈추면 도형으로 보정합니다. 압력을 세게 줄 필요는 없습니다.
- 지원 도형은 원·타원·사각형·직선입니다. 원래 비율·위치와 색·굵기·투명도를 유지하며, 도형으로 인식하지 못하면 원래 필기를 유지합니다.
- 그리는 도중에는 즉시 자유 필기를 표시합니다. 홀드 시간이 전체 필기 입력을 지연시키면 안 됩니다.
- 보정 후에는 그 모양을 고정하고 펜을 떼면 확정합니다. 실행 취소 한 번은 보정된 획 전체 삭제, 다시 실행은 그 도형 복원입니다.
- 하단 도구막대 옆에 도형 보정 켜기·끄기 토글을 둡니다. 기본 켜짐이며 사용자의 선택을 기억합니다. 꺼도 아이콘은 남고, 켜졌을 때만 파란색 선택 표시를 사용합니다.
- 올가미 도구로 일반 필기와 보정된 도형을 여러 개 선택하고 함께 이동·크기 조절할 수 있어야 합니다. 올가미 도구에서 도형 하나를 탭해 선택하는 것도 지원합니다.
- 선택 테두리 안쪽을 드래그하면 이동합니다. 모서리 4개 조절점은 비율을 유지하며 확대·축소하고, 변 가운데 4개 조절점은 가로 또는 세로만 조절합니다.
- 선택·편집 결과는 태블릿과 선택한 Windows 모니터에 동일하게 반영되어야 합니다. 태블릿 확대·이동은 Windows 배율을 바꾸지 않습니다.
- 자주 사용하는 색상을 기존 7색보다 늘립니다. 두 태블릿 플랫폼의 팔레트를 일치시키고 색상 이름 왼쪽에 실제 색 미리보기를 표시합니다.
- 지우개 버튼을 누르면 소·중·대 포인터 크기를 바로 선택합니다. 지우는 범위 미리보기와 선택한 크기 기억을 지원합니다. 굵기 버튼은 펜 굵기 전용이며 지우개 크기와 분리합니다.

사용자는 갤럭시에서 모니터를 바꿔도 영상이 바뀌지 않지만 필기는 전환된 모니터에 반영되는 듯한 증상을 추가로 보고했습니다.
정확한 두 화면의 변화 순서는 확인 중이며, 이 전환 문제를 우선 진단한 뒤 위 확장을 진행합니다.

## 연결과 성능

- 낮은 지연이 가장 중요합니다. USB를 우선 검증하고 유선 이더넷과 비교합니다.
- iPad의 필기는 네트워크 왕복을 기다리지 않고 로컬에 먼저 표시합니다.
- 영상 전송과 필기 이벤트 처리를 분리해, 영상 처리 지연이 펜 이벤트를 불필요하게 막지 않게 합니다.
- 구체적인 지연 수치는 실기기로 측정합니다. iPad 로컬 표시, Windows 반영, 화면 전송, Zoom 수신 지연을 나누어 기록합니다.
- Mac은 iPad 앱 빌드와 설치에 사용합니다. 완성 앱의 일상 사용에는 Windows와 iPad만 필요하도록 합니다.

## 첫 버전 범위 밖

- iPad를 통한 Windows 마우스·키보드 원격 조작
- 두 PC 동시 표시 및 동시 필기
- 문서 내부 객체나 페이지에 결합된 필기
- 계정 서비스, 클라우드 동기화, 결제, 공개 앱 배포 운영
- Zoom 자체 자동화
