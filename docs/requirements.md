# 확정한 요구사항

이 문서는 대화에서 사용자가 정한 요구사항을 기록합니다. 기술 선택과 아직 검증하지 않은 성능은 별도 설계 문서에서 구분합니다.

## 사용자와 기기

- 우선 사용자 본인이 사용합니다. 이후 타인에게 배포할 수 있는 구조를 유지합니다.
- Windows PC 두 대를 등록하고, iPad에서 한 번에 한 대를 선택해 연결합니다.
- 현재 사용 기기는 iPad Air와 Apple Pencil 2입니다. 지원 OS 범위 안의 다른 iPad와 입력 장치도 기본 기능을 사용할 수 있어야 합니다.
- PC별 연결 정보와 필기를 구분합니다. 모니터가 여러 개인 PC에서는 필기할 모니터를 선택합니다.
- 같은 PC의 화면 1·2 바로가기 또는 Stream Deck 버튼으로 실행 중인 앱의 모니터를 전환합니다. 화면 1의 필기는 화면 1에, 화면 2의 필기는 화면 2에 유지합니다. 실행 취소 기록도 화면별로 구분합니다. 사용자가 2026-10-18에 선택한 동작입니다.
- PC 조작은 기존 마우스로 합니다. 앱의 필기층이 Windows 마우스 조작을 가로막지 않아야 합니다.
- Zoom 화면 공유는 사용자가 직접 합니다. 앱이 Zoom을 조작하거나 회의를 시작하지 않습니다.

## 발표 흐름

1. Windows 프로그램을 실행해 두고 iPad를 연결합니다.
2. iPad 앱에서 기억된 PC와 모니터를 선택합니다. 정상 재연결에서는 불필요한 설정을 반복하지 않습니다.
3. Windows 화면을 보며 펜으로 필기합니다. Windows에는 동일한 필기와 펜 위치 표시가 나타납니다.
4. 사용자는 평소처럼 Zoom에서 모니터 하나를 공유합니다.
5. 필기 숨기기, 전체 지우기, 도구 전환을 짧은 동작으로 수행합니다.

## 화면과 필기

- Windows의 임의 화면 위에 필기합니다. PowerPoint 전용 기능이 아닙니다.
- iPad에서 화면을 확대·이동해도 Windows의 배율은 변하지 않습니다.
- 두 손가락 벌리기·오므리기로 확대·축소하고 두 손가락 드래그로 이동합니다. 도구막대는 고정하며 화면 맞춤으로 원래 보기로 돌아갑니다. 사용자는 현재 이 기능을 우선 완성하도록 요청했습니다.
- 도구막대는 아래쪽 검은 영역에 두고 영상을 가리지 않습니다. 영상은 도구막대 위 공간에 비율을 유지해 전체가 보이도록 맞추며, 확대된 영상과 필기도 도구막대 영역을 침범하지 않습니다.
- 확대 상태의 입력은 선택한 Windows 모니터의 원래 좌표에 정확하게 대응합니다.
- PDF 스크롤이나 PPT 페이지 전환 후에도 필기는 화면 위치에 유지됩니다. 문서 내용에 붙여 추적하지 않습니다.
- 필기는 사용자가 지우거나 숨깁니다. 전체 지우기와 숨기기는 서로 다른 동작입니다.
- 연결 중단과 앱 종료 후에도 PC별로 마지막 필기를 저장하고 복원할 수 있게 합니다. 마지막 제안에 대한 사용자의 “진행”을 반영한 결정입니다.

## 첫 버전 도구

- 펜, 형광펜, 지우개, 레이저 포인터, 일정 시간 후 사라지는 펜
- 색과 굵기 선택
- 실행 취소 / 다시 실행
- 전체 지우기 / 필기 숨기기
- Apple Pencil 2의 더블탭으로 지우개 전환
- 지운 뒤 펜을 화면에서 떼면 직전에 쓰던 도구로 자동 복귀하고 색·굵기를 유지
- 펜 또는 레이저의 위치를 Windows 화면에 표시

직선·화살표·도형 자동 생성은 첫 버전 필수 범위에 포함하지 않습니다.

압력, 기울기, 더블탭, 호버는 장치가 제공하는 기능만 사용합니다. 일반 터치와 Pencil 입력을 구분할 수 없는 입력 장치는 별도 터치 필기 모드가 필요할 수 있습니다. Pencil 2를 지원하는 iPad Air에서 공중 위치 추적을 가정하지 않습니다.

## 연결과 성능

- 낮은 지연이 가장 중요합니다. USB를 우선 검증하고 유선 이더넷과 비교합니다.
- iPad의 필기는 네트워크 왕복을 기다리지 않고 로컬에 먼저 표시합니다.
- 영상 전송과 필기 이벤트 처리를 분리해, 영상 처리 지연이 펜 이벤트를 불필요하게 막지 않게 합니다.
- 구체적인 지연 수치는 실기기로 측정합니다. iPad 로컬 표시, Windows 반영, 화면 전송, Zoom 수신 지연을 나누어 기록합니다.
- Mac은 iPad 앱 빌드와 설치에 사용합니다. 완성 앱의 일상 사용에는 Windows와 iPad만 필요하도록 합니다.

## 첫 버전 범위 밖

- iPad를 통한 Windows 마우스·키보드 원격 조작
- 두 PC 동시 표시 및 동시 필기
- 문서 내부 객체나 페이지에 결합된 필기
- 계정 서비스, 클라우드 동기화, 결제, 공개 앱 배포 운영
- Zoom 자체 자동화
