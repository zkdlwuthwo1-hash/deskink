01 / Windows first

먼저 PC에서 DeskInk를 실행하세요.

iPad와 갤럭시탭 모두 같은 Windows 앱을 사용합니다. PC 준비를 마친 뒤 아래에서 사용할 태블릿을 고르세요.

  1. 받은 ZIP을 전체 압축 해제

    문서 폴더 등 쓰기 가능한 위치에 압축을 풉니다. 폴더 안의 bin·scripts·licenses는 앱에 필요한 파일이므로 함께 보관하세요.

  2. DeskInk.exe 하나만 실행

    처음 한 번 영상 구성요소 약 60MB를 내려받습니다. 인터넷이 필요하며, 준비가 끝나면 PC 앱이 열립니다. 갤럭시탭용 USB 구성요소 약 8MB도 뒤에서 자동으로 준비합니다. 이미 준비되어 있으면 다시 받지 않습니다.

    USB 구성요소 다운로드가 실패해도 iPad·Wi-Fi/LAN 사용은 계속할 수 있습니다. 갤럭시탭 USB가 연결되지 않으면 인터넷을 확인하고 DeskInk를 완전히 종료한 뒤 다시 실행하세요.

  3. 바탕화면 아이콘 확인 후 태블릿 선택

    DeskInk - Screen 1 / Screen 2 아이콘이 자동으로 생깁니다. 다음부터 원하는 화면의 아이콘을 열면 됩니다. 아래에서 Apple 기기 또는 Galaxy 기기를 선택해 태블릿 설치를 이어가세요.

Apple 기기 · iPad 설치 순서

iPadOS 17+
Lightning iPad도 같은 앱으로 연결합니다.

iPadOS 17 이상이면 아래의 같은 설치 순서를 따르세요. PC의 USB-A 포트에는 USB-A–Lightning, USB-C 포트에는 USB-C–Lightning 데이터 전송용 케이블을 사용합니다. Apple 연결 안내

Apple Pencil 1세대는 두 번 탭 전환이 없으므로 아래 도구막대에서 지우개를 고릅니다. Apple Pencil 기능 안내

  1. 먼저 Apple 기기 앱에서 iPad 연결·등록

    처음 설정하는 Windows PC에서는 Apple 기기(Apple Devices) 앱을 설치하고 실행하세요. Windows가 iPad를 USB로 인식하는지 이 앱에서 먼저 확인합니다.

    Apple 기기 설치 · Microsoft Store

    아이패드를 데이터 전송용 USB 케이블로 연결하고 잠금을 풉니다. PC의 Apple 기기 앱에서 신뢰를 요청하면 신뢰를 누릅니다. 아이패드에도 이 컴퓨터를 신뢰가 나오면 허용하고 기기 암호를 입력하세요. Apple 공식 컴퓨터 신뢰 안내

    PC에서 Apple 기기 실행 → USB 연결
    → iPad 잠금 해제·컴퓨터 신뢰
    → Apple 기기 왼쪽 목록에서 내 iPad 확인

    처음 설정하는 PC는 Apple 기기 목록에 iPad가 표시되는 것을 확인한 뒤에만 다음 단계로 진행하세요. 이미 iloader·DeskInk에서 정상 인식되는 PC라면 Apple 기기를 추가 설치하지 않고 계속해도 됩니다. 이 연결·신뢰 등록은 나중에 입력하는 DeskInk의 6자리 페어링 코드와 별개입니다. 다음 단계에서 iloader를 설치·실행한 뒤 Refresh Devices / 기기 새로고침(Ctrl+R)을 누르고, 위쪽 iDevice에서 아이패드를 선택하세요. Apple 기기에는 보이는데 iloader에 없다면 iloader를 완전히 닫았다가 다시 엽니다.

    이미 Apple 기기를 설치하고 이 PC를 신뢰했다면 다시 설치·등록할 필요는 없습니다. iPad가 목록에 보이는지 확인하고 계속하세요. iTunes 등으로 Apple USB 연결 구성요소가 준비된 PC도 있지만, 이 안내서는 Apple 기기 앱으로 인식을 확인하는 순서입니다. 이 단계는 USB 설치·연결 준비이며, 설치 후 무선 화면 전송 자체에는 Apple USB 서비스가 필요하지 않습니다. Apple 공식 USB 인식 안내

  2. iloader에서 기기를 선택하고 인증 서버 확인

    iloader 설치 파일과 iPad IPA를 Windows PC에 내려받습니다. iloader를 실행해 Refresh Devices를 누르고, 위쪽 iDevice에서 아이패드를 선택하세요.

    처음에는 기본 서버로 진행하세요. 아래쪽 Settings → Anisette Server는 Apple 로그인에 필요한 인증 정보를 준비하는 서버입니다. Windows PC에서도 Jkcoxson (Mac)을 사용할 수 있습니다. 이름의 Mac·Windows는 서버 종류이며, 사용하는 컴퓨터의 운영체제와 맞출 필요가 없습니다.

    2026년 10월 22일 나온 iloader 2.4.0은 Jkcoxson (Mac)을 기본값으로 쓰고 기존 Windows 서버를 목록에서 제거했습니다. 이전 버전에서 로그인에 실패했다면 iloader를 업데이트하고, 이 항목이 있으면 선택해 다시 로그인하세요. 정상 로그인 중이라면 바꿀 필요는 없습니다. 개발자의 변경 안내

  3. Apple ID에 본인 계정으로 로그인

    왼쪽 Apple ID에서 Apple ID Email…에 Apple 계정 이메일을, Apple ID Password…에 그 계정의 비밀번호를 넣고 Login을 누릅니다. Save Credentials는 로그인 정보 저장 선택 항목입니다. 비밀번호를 이 안내 페이지에 입력하는 것은 아닙니다.

    이미 Logged in as 아래에 본인 계정과 Sign Out이 보이면 로그인된 상태입니다. 다시 로그인하지 않고 IPA 설치 단계로 넘어가세요. Saved Logins에 계정만 있다면 해당 계정의 Sign in을 누릅니다.

  4. iPad·iPhone의 Apple 이중 인증 확인

    본인이 시작한 로그인 요청이 iPad·iPhone에 오면 허용을 누릅니다. Apple이 알려 주는 6자리 확인 코드를 PC iloader의 Two-Factor Authentication → Verification Code…에 입력하고 Submit을 누르세요. 인증창이 나오지 않고 바로 로그인되었다면 다음 단계로 진행합니다. Apple 확인 코드 안내

    Apple 확인 코드와 DeskInk 페어링 코드는 다릅니다.

    지금 코드는 Apple 로그인 → iloader에 입력합니다. 나중의 DeskInk PC 연결 코드 → 태블릿 DeskInk에 입력과 구분하세요.

    로그인이 안 되면 오류별 확인 방법을 먼저 보세요. 서버 변경이 모든 로그인 오류를 해결하는 것은 아닙니다.

  5. Import IPA로 DeskInk 설치

    로그인 후 iloader의 Installers → Import IPA를 누릅니다. PC의 다운로드 폴더에서 받은 DeskInk-iPad-unsigned.ipa를 선택하세요.

    Import IPA / IPA 가져오기
    → DeskInk-iPad-unsigned.ipa 선택
    → 서명·설치 시작: Sign & Install App 단계 완료까지 대기
    → 완료 후 iPad 홈 화면에서 DeskInk 확인

    설치하는 동안 아이패드 잠금을 풀어 두고 USB 연결을 유지하세요. 설치가 끝나면 iloader는 닫아도 됩니다. iTunes 등 Apple 구성요소가 필요하다는 안내가 나오면 iloader 공식 안내를 따릅니다.

  6. 개발자 신뢰와 개발자 모드 켜기

    “개발자를 신뢰할 수 없음”이 나오면 다음 설정에서 본인 계정을 신뢰합니다.

    설정 → 일반 → VPN 및 기기 관리
    → 개발자 앱 → 본인 Apple 계정 → 신뢰

    그다음 개발자 모드를 켭니다.

    설정 → 개인정보 보호 및 보안
    → 개발자 모드 → 켜기 → 재시동

    재시동 후 잠금을 풀고 확인창의 ‘켜기’를 한 번 더 누르세요. 기기 암호를 요청하면 입력합니다. Apple 공식 안내

    메뉴가 없다면 iloader로 IPA를 설치하고 DeskInk 실행을 한 번 시도한 뒤 설정을 다시 여세요. 학교·회사 관리 기기는 설정이 제한될 수 있습니다.

무료 Apple 계정은 7일마다 설치를 갱신합니다.

USB로 연결하고 iloader의 같은 계정 → Import IPA → 같은 IPA 선택으로 다시 설치하세요. Sign & Install App 단계가 완료될 때까지 기다립니다. Apple 계정 자체가 만료되는 것은 아닙니다. Apple 무료 계정 안내

03 / Wi-Fi & LAN

같은 네트워크에서,
QR이나 IP로 PC를 선택하세요.

USB 연결을 우선 사용하고, USB가 없으면 기억한 PC 주소로 자동 연결합니다. Windows의 무선 연결 허용은 처음 한 번 직접 켜세요. 현재 권장 조합은 Windows 0.5.3와 태블릿 앱 0.5.1입니다. 0.5.1보다 이전인 앱은 먼저 업데이트하세요. PC는 이더넷, 태블릿은 같은 공유기의 Wi-Fi로 연결해도 됩니다.

선택 기능 · 기본 꺼짐

  1. PC와 태블릿을 같은 로컬 네트워크에 연결

    두 기기가 서로 통신할 수 있는 공유기·네트워크를 사용합니다. PC는 유선 이더넷을 권장하며, 태블릿은 신호가 강한 5/6GHz Wi-Fi를 사용하세요. 인터넷을 통한 외부 원격 접속은 지원하지 않습니다.

  2. Windows에서 연결 허용하고 IP·포트 확인

    USB를 빼고 태블릿 연결을 종료합니다. Windows DeskInk의 Wi-Fi / LAN 카드에서 Allow Wi-Fi / LAN을 켜세요. PC에 LAN 케이블을 연결하는 것과 별개의 설정입니다. 태블릿 연결 중에는 이 설정을 바꿀 수 없습니다.

    PC ADDRESS의 IPv4 주소와 바로 아래 Port를 확인합니다. 기본 포트는 9876입니다. PC 주소는 Copy IP로 복사할 수 있습니다. 태블릿의 IP가 아니라 연결하려는 Windows PC의 IP를 넣으세요.

    VPN·가상 어댑터 대신 태블릿과 통신할 수 있는 주소인지 확인하고, 네트워크를 바꿨다면 Refresh IP를 누릅니다.

  3. iPad: QR로 읽거나 IP를 직접 입력

    Windows의 QR code (iPad)를 누르면 아래처럼 QR이 열립니다. iPad DeskInk의 Scan QR code를 눌러 PC 화면의 QR을 읽으세요. 카메라·로컬 네트워크 접근 요청은 허용합니다.

    직접 입력할 때는 iPad의 무선 / IP 연결에서 PC address에 PC 주소, Port에 포트를 넣고 Connect를 누릅니다. 이번 버전은 Find PCs 대신 Scan QR code 또는 IP 입력을 사용하세요.

    Windows의 PC ADDRESS → iPad의 PC address
    Windows의 Port → iPad의 Port
    → Connect

신뢰하는 로컬 네트워크에서 사용하세요.

화면과 필기 데이터는 암호화되지 않습니다. Windows 방화벽은 압축을 푼 폴더의 bin/deskink.exe에 대해 개인 네트워크·UDP 9876·로컬 서브넷 범위로 허용합니다. 방화벽을 끄거나 공유기 포트 포워딩을 설정하지 마세요. 다른 포트로 설정했다면 표시된 포트와 허용 규칙을 맞춥니다.

지연과 연결 상태

무선은 전파·공유기 상태에 따라 지연이 달라져 지연 0을 보장하지 않습니다. 오래된 필기가 길게 쌓이지 않도록 처리하며, 연결 상태가 나쁘면 다시 연결하거나 USB로 돌아가세요. 자동 검사는 입력 순서·손실 복구·대기량 제한을 대상으로 합니다. 실제 Wi-Fi 지연, 펜 감각과 Zoom 발표는 실기기 확인이 필요합니다.

USB 우선 자동 연결

LAN으로 한 번 정상 연결하면 PC 주소를 기억합니다. USB 데이터 연결이 가능하면 USB를 사용하고, 없으면 기억한 PC의 IP로 자동 연결합니다. 케이블을 다시 꽂으면 USB로 돌아갑니다. X·연결 해제를 누르면 자동 재연결도 멈춥니다. USB로만 쓰던 PC는 먼저 IP를 한 번 입력해야 하며, 주소가 바뀌면 다시 입력하세요. 연결 전환 중에는 화면이 잠깐 멈출 수 있습니다.

무선 전송 자체에는 Apple USB 서비스나 Android USB 디버깅이 필요하지 않지만, iPad의 iloader 설치·7일 갱신은 위의 USB 절차를 사용합니다.

IP를 넣어도 무선 연결이 안 되나요?

현재 배포 조합인 Windows 0.5.3·태블릿 0.5.1을 사용하는지, Windows의 Allow Wi-Fi / LAN이 켜져 있는지, PC의 현재 IP와 포트를 입력했는지 확인합니다. 페어링 코드만으로 PC를 찾을 수는 없으므로 먼저 주소를 입력하거나 QR을 읽으세요.

iPad는 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → DeskInk의 접근 허용을 확인합니다. 게스트 Wi-Fi, 기기 간 통신 차단, 서로 다른 서브넷이나 VPN 때문에 인터넷이 되더라도 PC에 접속할 수 없을 수 있습니다. Windows의 개인 네트워크·로컬 서브넷 방화벽 허용도 확인하세요. 기관 네트워크라면 담당자에게 같은 네트워크의 기기 간 통신 허용 여부를 확인합니다.

페어링 창이 바로 사라지거나 PC 수신 포트가 열렸다 닫히면 Windows 화면 캡처 호환성도 확인하세요.

업데이트 후에도 코드가 필요한가요?

0.4.2 이전 버전에서 업데이트했다면 Windows와 태블릿 앱을 모두 업데이트하고, 각 PC에서 마지막으로 한 번 등록하세요. 다음부터 USB 연결과 DeskInk 실행만 하면 됩니다. PC 앱의 Forget paired tablets를 누르면 등록이 해제되어 코드가 다시 필요합니다. 앱 재설치·데이터 초기화나 Windows 사용자 계정 변경 시에도 다시 등록해야 할 수 있습니다.

Windows 업데이트도 매번 파일을 받아야 하나요?

0.5.1부터 Windows 앱이 새 버전을 자동으로 확인합니다. App updates를 펼쳐 Download update로 받은 뒤 Install and restart (clears ink)를 누르면 설치·재시작합니다. 발표 도중 자동으로 재시작하지 않습니다. 새 버전이 표시되지 않으면 작업을 마친 뒤 DeskInk를 완전히 종료하고 다시 열어 업데이트를 확인하세요. 기존 모니터 아이콘과 페어링 정보는 유지되며, 재시작하면 현재 필기는 지워집니다.

Windows가 0.5.1보다 이전이면 최신 Windows ZIP을 한 번 받아야 합니다. 기존 DeskInk를 종료하고, 새 ZIP의 전체 내용을 기존 DeskInk 폴더에 덮어쓴 뒤 그 폴더의 DeskInk.exe를 실행하세요. 폴더 위치를 유지하면 기존 아이콘도 그대로 쓸 수 있습니다. 태블릿이 0.5.1보다 이전일 때만 함께 업데이트하세요. iPad는 iloader에서 새 IPA를 설치하고, Android는 새 APK를 기존 앱 위에 설치합니다. Windows 0.5.3 실행 파일 통합 업데이트만으로는 태블릿 재설치가 필요하지 않습니다.

“Different versions — update both” 또는 “EternalMonitor”가 나와요.

PC와 태블릿 앱의 연결 방식이 서로 호환되지 않는다는 뜻입니다. Windows와 태블릿 앱 중 0.5.1보다 이전인 앱이 있으면 업데이트하세요. Windows 0.5.3와 태블릿 0.5.1은 호환되므로 버전 숫자를 똑같이 맞출 필요는 없습니다. iPad는 새 IPA를 iloader의 Import IPA에 불러와, 기존과 같은 Apple 계정으로 설치합니다. 앱을 지울 필요는 없습니다.

코드를 입력했는데 Connection lost — USB disconnected가 떠요.

이 메시지만으로 케이블 고장이라고 판단할 수는 없습니다. 먼저 Windows 앱을 업데이트하세요. 0.4.4 이전 버전에서는 Intel 영상 압축이 실패해도 USB 연결이 종료되어 이 메시지가 나타났습니다.

계속 실패하면 Apple 기기에서 iPad가 인식되는지 확인하세요. Windows의 %LOCALAPPDATA%\DeskInk\logs 폴더에서 같은 시각의 stdout·stderr 로그 두 파일로 원인을 확인할 수 있습니다. 로그를 공개할 때는 기기·연결 정보를 가려주세요. 무선에서만 실패한다면 네트워크 연결 확인을 따르세요.

PC에 코드가 안 보여요.

iloader나 Apple Devices가 아니라 Windows의 DeskInk 창을 엽니다. ZIP을 전체 압축 해제하고 DeskInk.exe를 실행하세요. iPad와 갤럭시탭 모두 같습니다. 바탕화면 아이콘으로 실행한 경우 작업 표시줄에서 DeskInk 창을 찾습니다.

태블릿에 입력창이 안 떠요.

PC와 태블릿 양쪽에서 DeskInk를 열고 USB 케이블을 확인하세요. iPad는 컴퓨터 신뢰와 Apple USB 연결 서비스를 확인합니다. 앱의 USB 항목이 꺼져 있으면 Turn on, 연결이 끊긴 상태라면 표시된 Connect USB를 누릅니다. Android는 USB 디버깅 허용 후 시작 화면의 PC 연결을 누릅니다. 이미 PC 화면이 보이면 연결된 상태입니다.

코드가 틀렸거나 너무 많이 시도했다고 나와요.

PC 창의 현재 코드를 다시 보고 6자리를 입력하세요. 재시작하거나 연결에 성공하면 숫자가 바뀔 수 있습니다. Too many attempts / 시도 횟수가 많습니다가 나오면 1분 기다린 뒤 다시 입력합니다.

iPad 안내에 EternalMonitor라고 나와요.

현재 iPad 앱의 일부 안내에 남아 있는 이름입니다. 실제 코드는 Windows DeskInk 창의 Pairing code에서 확인하면 됩니다. 이 안내의 USB 연결에서는 PC 주소나 포트를 직접 입력하지 않아도 됩니다.

ZIP 안에서 바로 실행하지 말고 전체 압축을 풀어 주세요. 첫 실행에는 인터넷과 폴더 쓰기 권한이 필요합니다. 오류 로그는 %LOCALAPPDATA%/DeskInk/logs에서 확인할 수 있습니다.

아이패드가 PC나 iloader에 나타나지 않아요.

Apple 기기 설치·연결 확인 단계부터 확인하세요. iPad 잠금을 풀고 이 컴퓨터 신뢰를 허용합니다. Apple 기기의 왼쪽 목록에도 안 보이면 데이터 전송용 케이블과 다른 USB 포트를 사용해 보세요. Apple 기기에는 보이면 iloader의 Refresh Devices / 기기 새로고침(Ctrl+R)을 누르고, 계속 없으면 iloader를 다시 실행합니다. Apple 구성요소가 없다는 오류는 iloader 공식 설치 안내를 따르세요.

Apple Devices를 계속 열어 둬야 하나요?

모든 PC에서 필요한 것은 아닙니다. DeskInk는 Apple의 USB 연결 서비스가 동작하면 연결할 수 있습니다. Apple Devices를 열지 않아도 정상 연결된다면 그대로 사용하세요. 해당 앱을 닫았을 때 연결이 끊기는 환경에서만 사용 중 최소화해 두면 됩니다.

iloader Apple 로그인·이중 인증이 안 돼요.

502·503·Anisette·non-plist: 인증 서버나 통신 문제일 수 있으며, 이 메시지만으로 비밀번호가 틀렸다고 판단할 수 없습니다. 잠시 뒤 다시 시도하고, iloader를 최신 버전으로 업데이트하세요. Settings → Anisette Server에 Jkcoxson (Mac)이 있으면 선택한 뒤 로그인해 보세요. Windows PC에서도 사용할 수 있습니다. 현재 서버가 이미 이 항목이라면 목록에 있는 다른 Mac 서버를 시도할 수 있습니다. 서버 설정 사진 · iloader 2.4.0 서버 변경 안내

계정 정보가 잘못되었다는 오류: 계정 이메일·비밀번호를 다시 확인하세요. 필요하면 Apple 계정 공식 사이트에서 본인이 로그인되는지 확인합니다. 비밀번호나 확인 코드를 다른 사람에게 보내지 마세요.

인증 코드 대기: 본인 iPad·iPhone의 Apple 로그인 알림에서 허용을 누르고, 나온 6자리 코드를 iloader의 Verification Code에 넣습니다. 문자 인증이 진행되지 않는 구버전은 iloader를 업데이트해 다시 시도하세요. iloader에 없는 ‘문자 재전송’ 버튼을 찾을 필요는 없습니다. 인증창 사진 · Apple 확인 코드 안내

정상 로그인됐다면 서버를 바꾸거나 계정을 다시 추가하지 않아도 됩니다. 서버 변경은 대안이며, 계정 상태·네트워크에 따른 모든 오류를 해결하지는 않습니다. 확인한 버전·공식 소스

갤럭시탭이 PC에 나타나지 않아요.

PC에서 DeskInk.exe를 열고 자동 USB 구성요소 준비를 잠시 기다리세요. 다운로드가 실패했다면 인터넷을 확인하고 DeskInk를 완전히 종료한 뒤 다시 실행합니다. USB 디버깅을 켜고 태블릿에서 이 PC를 허용합니다. 앱을 열어 두고, 필요하면 삼성 USB 드라이버를 설치하세요.

개발자의 앱을 사용할 수 없다고 나와요.

iPad의 개발자 신뢰·개발자 모드 설정을 확인하세요. 재시동 후 켜기 확인까지 마쳐야 합니다. 설치한 지 일주일이 지났다면 iloader에서 서명·설치 갱신을 진행하세요.

페어링 코드 입력이 어려워요.

PC에서 코드 찾기 → 태블릿에 입력하기 안내를 보세요. 코드가 안 보이거나, 입력창이 없거나, 오류가 날 때의 해결 방법을 함께 정리했습니다.
