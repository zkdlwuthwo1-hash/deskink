# 작업 관리: 로컬 파일

사용자가 로컬 작업 관리 구성을 수락했습니다. 이 프로젝트의 작업은 외부 서비스에 게시하지 않고 저장소 안의 파일로 관리합니다.

- 제품 요구사항: `docs/requirements.md`
- 구조 및 작업 순서: `docs/implementation-plan.md`
- 테스트 범위: `docs/verification-plan.md`
- 승인 후 작업별 티켓: `.scratch/desk-ink/issues/NN-작업명.md`
- 작업 하나당 티켓 파일 하나를 작성합니다.
- 각 티켓에 `Blocked by`와 `Status`를 기록합니다. 실제 완료 조건을 충족한 작업만 완료로 표시합니다.
- 상태 이름: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. 진행 및 완료 상태는 필요할 때 별도로 명시합니다.
- 구현 전 검토안은 승인된 티켓으로 게시된 것으로 간주하지 않습니다.
