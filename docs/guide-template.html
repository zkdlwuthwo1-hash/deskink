Windows 화면에
태블릿으로 필기하기

논문, 슬라이드, 코드를 띄운 화면이 그대로 칠판이 됩니다. 아이패드나 갤럭시탭을 USB로 연결하고 펜으로 쓰세요. PC 조작은 평소처럼 마우스로 합니다.

Windows ZIP 다운로드 Android APK 다운로드 iPad IPA 다운로드 iloader Windows 다운로드

Windows ZIP·iPad IPA·iloader는 PC에서, Android APK는 태블릿에서 받으세요. 내려받은 파일을 열고 아래 순서로 설치합니다. iloader 버튼은 공식 배포처의 Windows 설치 파일로 연결됩니다.

준비물: 최신 Windows x64 PC · iPadOS 17+ 또는 Android 8+ 태블릿 · 호환 펜 · 데이터 USB 케이블
Mac이나 개발 도구 없이 설치할 수 있습니다. 첫 PC 설정에는 인터넷이 필요합니다.

Galaxy Tab · Android에 설치하기

Android판은 APK 파일로 설치합니다. Windows용 ZIP은 iPad판과 같은 파일을 사용하며, Android 연결 도구를 처음 한 번 준비합니다.

1

태블릿에 APK 설치

태블릿에서 Android APK 다운로드를 누릅니다. 내려받은 DeskInk-Android.apk를 열고 설치를 누르세요. 요청이 나오면 사용 중인 브라우저 또는 내 파일 앱의 출처를 알 수 없는 앱 설치를 허용합니다.

2

개발자 옵션과 USB 디버깅 켜기

설정 → 태블릿 정보 → 소프트웨어 정보
→ 빌드번호 7번 누르기 → 기기 암호 입력
→ 설정의 개발자 옵션 → USB 디버깅 켜기

기기별 메뉴 이름이 다를 수 있습니다. 삼성 공식 안내

3

Windows ZIP을 풀고 Android 연결 준비

PC에서 Windows ZIP 다운로드를 누릅니다. 전체 압축 해제한 뒤 DeskInk-Android.exe를 한 번 엽니다. Google USB 도구 약 8MB와 영상 구성요소 약 60MB를 내려받고 검사합니다. 첫 준비에는 인터넷이 필요합니다.

이때 바탕화면에 DeskInk - Screen 1 / Screen 2 아이콘도 생깁니다. 다음부터 원하는 아이콘을 더블클릭하세요.

4

USB 연결을 허용하고 페어링

태블릿을 데이터 케이블로 연결하고 이 컴퓨터에서 USB 디버깅 허용을 누릅니다. 태블릿 DeskInk를 열고 PC에 표시된 6자리 페어링 코드를 입력하세요. Android 태블릿은 한 번에 한 대만 연결합니다.

S Pen 버튼은 누르는 동안 지우개
버튼을 놓으면 사용하던 펜·형광펜 등으로 돌아옵니다. 버튼 없는 펜은 도구막대의 지우개를 사용하세요. Android는 Apple 계정·iloader가 필요 없고 7일마다 재설치하지 않습니다.

Windows에서 태블릿이 잡히지 않으면 삼성 USB 드라이버도 확인하세요. USB 디버깅은 연결할 PC에 허용하고, 사용하지 않을 때는 끌 수 있습니다.

iPad에 설치하기

Windows + DeskInk↔ USB ↔iPad + DeskInk
1

Apple Devices로 USB 연결 준비

Microsoft Store에서 Apple Devices를 설치하고 엽니다. 아이패드를 USB로 연결한 뒤 잠금을 풀고 이 컴퓨터를 신뢰를 누르세요. DeskInk를 사용하는 동안 Apple Devices를 열어 둡니다.

2

Windows ZIP을 풀고 실행

PC에서 Windows ZIP 다운로드를 누릅니다. 문서 폴더 등 쓰기 가능한 위치에 전체 압축 해제하고 DeskInk.exe를 엽니다.

첫 실행에서 영상 구성요소 약 60MB를 배포처에서 내려받아 검사합니다. 이때 인터넷이 필요하며, 다음 실행부터는 재사용합니다. 폴더 안의 파일들은 함께 보관하세요. 첫 실행 때 바탕화면에 화면 1·화면 2 아이콘이 자동으로 생깁니다.

3

iloader에서 iPad IPA 설치

PC에서 iPad IPA와 iloader Windows 설치 파일을 받습니다. iloader 설치 파일을 실행하고, 설치된 iloader에서 연결된 아이패드를 선택합니다.

  1. 본인 Apple 계정으로 로그인하고 이중 인증을 완료합니다.
  2. Import IPA / IPA 가져오기에서 내려받은 DeskInk-iPad-unsigned.ipa를 고릅니다.
  3. Sign & Install App을 누르고 설치 완료를 기다립니다.

iloader는 무료입니다. Windows에서 iTunes를 요구하므로 Apple 구성요소가 없다는 메시지가 나오면 공식 설치 안내를 따르세요. 버튼 이름은 버전·언어에 따라 조금 다를 수 있습니다.

iPad에서 실행 허용하기

IPA 설치가 끝나도 처음에는 실행이 막힐 수 있습니다. 개발자 신뢰와 개발자 모드를 아래 순서로 확인하세요.

1

“개발자를 신뢰할 수 없음”이 나오면

설정 → 일반 → VPN 및 기기 관리
→ 개발자 앱 → 본인 Apple 계정 → 신뢰

추가 확인이나 재시동 안내가 나오면 따릅니다.

2

개발자 모드 켜기

설정 → 개인정보 보호 및 보안
→ 개발자 모드 → 켜기 → 재시동

재시동 후 잠금을 풀고, 확인창의 ‘켜기’를 한 번 더 누르세요.

기기 암호를 요청하면 입력합니다. 이제 홈 화면에서 DeskInk를 엽니다.

‘개발자 모드’ 메뉴가 안 보인다면
iloader로 IPA를 먼저 설치하고 DeskInk 실행을 한 번 시도한 뒤 설정을 다시 여세요. 학교·회사 관리 기기에서는 이 설정이 제한될 수 있습니다.

설정 화면의 표현은 iPadOS 버전에 따라 조금 다를 수 있습니다. Apple 개발자 모드 안내

연결하고 필기하기

USB 연결을 유지한 채 PC에서 DeskInk를 엽니다. iPad를 쓰는 경우 Apple Devices도 열어 둡니다. PC의 Screen 1 / Screen 2를 고른 뒤, 태블릿 DeskInk에 PC에 표시된 페어링 코드를 입력합니다. PC DeskInk를 재시작하면 다시 페어링합니다.

펜 · 형광펜

Pencil 또는 S Pen으로 필기를 남깁니다. 색상과 굵기에서 원하는 모양을 고릅니다.

지우개

닿은 선을 통째로 지웁니다. 펜을 떼면 이전 도구로 복귀합니다. 지원 Pencil은 두 번 탭으로도 전환합니다. S Pen 버튼은 누르는 동안 지우개, 놓으면 이전 도구입니다.

레이저 · 사라지는 펜

위치를 가리키거나 약 2초 뒤 사라지는 선을 남깁니다. 화면에 대기 전 포인터 표시는 호버 지원 기기가 필요합니다.

취소 · 다시 · 눈 · 휴지통

실행 취소/다시 실행, 필기 숨기기/보이기, 현재 모니터 전체 지우기입니다. 전체 지우기도 취소할 수 있습니다.

태블릿에서만 확대·이동

두 손가락을 벌리면 1~4배 확대되고, 두 손가락으로 끌면 화면이 이동합니다. 화면 맞춤을 누르면 돌아옵니다. Windows 화면의 배율은 그대로이며, 손가락으로는 기본적으로 필기되지 않습니다.

바탕화면 아이콘으로 화면 전환

Windows 첫 실행 때 바탕화면에 DeskInk - Screen 1 / Screen 2가 자동으로 생깁니다. 누구나 원하는 아이콘을 더블클릭하면 실행 중인 DeskInk의 화면이 터미널 창 없이 바뀝니다. 영상은 잠시 다시 연결됩니다.

Stream Deck을 쓰는 분은 같은 아이콘을 열기 동작에 등록해도 됩니다. 아이콘을 지웠거나 설치 폴더를 옮겼다면 DeskInk-Shortcuts.exe로 다시 만드세요.

DeskInk 번호는 Windows 디스플레이 설정의 번호와 다를 수 있습니다. 바로가기를 만든 후에는 압축을 푼 폴더를 같은 위치에 두세요.

Zoom 발표와 종료

Zoom에서는 직접 필기하는 모니터 전체를 공유하고 상대방에게 필기·포인터가 보이는지 확인하세요. 특정 앱 창만 공유하면 필기가 빠질 수 있습니다.

iloader는 설치 후 꺼도 됩니다. 사용 중에는 DeskInk를 켜 두고 USB를 연결해 두세요. 화면별 필기는 실행 중에 따로 유지되지만, Windows DeskInk를 종료하면 모두 지워집니다. 영구 저장 기능은 없습니다.

iPad만: 7일마다 설치 갱신하기

무료 Apple 계정으로 설치한 개발용 앱의 서명은 7일 후 만료됩니다. Apple 계정이 만료되거나 iloader 유료 체험이 끝나는 것은 아닙니다.

USB 연결 → iloader 로그인 → 같은 IPA 선택 → Sign & Install App을 같은 Apple 계정으로 다시 진행하세요. 기존 앱 위에 다시 설치하며, 구독 없이 갱신합니다.

Apple 무료 계정 제한 안내

막힐 때 확인하기

갤럭시탭이 연결되지 않아요

DeskInk-Android.exe를 한 번 실행했는지, USB 디버깅과 PC 허용을 마쳤는지 확인하세요. 태블릿 앱을 켜고 데이터 케이블·삼성 USB 드라이버를 확인합니다.

아이패드가 PC에 나타나지 않아요

아이패드 잠금을 풀고 컴퓨터 신뢰를 확인하세요. Apple Devices를 열고, 충전 전용이 아닌 데이터 케이블과 다른 USB 포트를 시험하세요.

개발자 앱을 사용할 수 없거나 개발자 모드가 필요하대요

실행 허용하기를 따라 개발자 신뢰와 개발자 모드를 확인하세요. 재시동 후 켜기 확인을 마쳐야 합니다. 일주일 뒤부터 안 열린다면 iloader로 다시 서명·설치하세요.

Windows DeskInk가 실행되지 않아요

ZIP 안에서 바로 실행하지 말고 전체 압축을 푸세요. 첫 실행에는 인터넷과 폴더 쓰기 권한이 필요합니다. 오류 로그는 %LOCALAPPDATA%/DeskInk/logs에 있습니다. 문제 제보 시 페어링 코드와 개인 화면 내용은 제외하세요.

현재 연결 방식은 USB입니다. 기기별 확인 내용은 지원·검증 범위에서 볼 수 있습니다.
