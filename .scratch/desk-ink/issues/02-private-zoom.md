# 02: iPad만 확대해서 정확히 필기하기

**What to build:** iPad에서 확대·이동한 상태로 그려도 Windows의 배율은 유지되고 원래 위치에 필기한다.

**Blocked by:** None (기존 USB 연결과 도구막대 입력 확인 후 사용자가 확대 기능을 우선 요청)
**Status:** in-progress

2026-10-16: 두 손가락 벌리기·오므리기로 iPad만 1–4배 확대하고 두 손가락 드래그로 이동한다. 영상과 로컬 필기는 같은 UIKit 화면 안에서 함께 변환하며, 도구막대는 고정한다. 화면 맞춤 버튼으로 배율을 되돌린다. Pencil 입력 중에는 손가락에 의한 이동을 멈추고 Windows 모니터 좌표로 계속 전송한다. Windows 화면 크기·해상도·배율이나 PC 마우스 동작은 변경하지 않는다.

추가 요청: 위·아래 제어 영역과 영상 영역을 분리한다. 아래 검은 영역에 도구막대를 두고 영상은 그 위에서 비율을 유지한다. 기본 배율에서 전체 영상이 보여야 하고 확대해도 도구막대와 겹치지 않아야 한다.

- [x] 실제 입력 경로의 확대·이동 좌표가 정확하다. (UIKit 화면 변환 → 실제 canvas 시작 입력 → 전송 명령 검사)
- [x] 여백 입력을 거부하고 화면 맞춤·회전 후 필기와 좌표를 유지한다. 전체 iPad 단위 테스트 162개 통과(38912017205).
- [x] 실제 시뮬레이터 핀치·두 손가락 이동·확대 중 도구 터치·화면 맞춤을 확인한다(38911762479).
- [x] 위·아래 제어 영역과 영상 영역이 겹치지 않는 배치를 검사한다. 단위 162개와 UI 2개 통과(38913462937), 실행 중 가로 회전 후 전체 영상 영역·화면 맞춤·휴지통 접근 검사 통과(38914118802).
- [ ] 실기기 손가락 제스처와 Pencil 입력을 함께 확인한다.
